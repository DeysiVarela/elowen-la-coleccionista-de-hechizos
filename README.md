# Elowen, la Coleccionista de Hechizos

Videojuego 3D de puzzles y exploración hecho en Unity 6 (URP) para el proyecto final del curso de videojuegos.

## Historia

Elowen es una elfa maga longeva a la que le encanta coleccionar hechizos. Al entrar a una torre antigua cubierta por el bosque, debe aprender nuevos hechizos para llegar a la biblioteca y recuperar el último grimorio.

## Mecánica principal

El cristal del bastón de Elowen cambia de color según el hechizo activo:

- **Hielo (azul):** congela agua para crear puentes.
- **Plantas (verde):** hace crecer enredaderas y plataformas.
- **Luz (amarillo):** revela caminos ocultos.

## El nivel

1. **Entrada:** aprende a moverse y consigue el primer hechizo.
2. **Zona central:** puzzles que combinan los hechizos.
3. **Biblioteca:** puzzle final y el grimorio que cierra el nivel.

## Controles

- WASD: moverse
- Espacio: saltar
- Q: cambiar de hechizo
- Clic izquierdo: lanzar hechizo
